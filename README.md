# Forma

Kişisel antrenman ve beslenme koçu. Tek dosyalık, internetsiz çalışan bir web uygulaması.

- Açmak için: `index.html` dosyasına çift tıkla.
- Notlar, kurallar ve yol haritası Obsidian kasasında: `Belgeler/Obsidian Vault/Forma/`
- Claude Code ile çalışmak için: bu klasörde Terminal aç ve `claude` yaz. Ayrıntılar Obsidian'daki "Claude Code Rehberi" notunda.
- Testler: `python3 tests/hepsi.py`
- `kurulum-ayarlari.json`: Claude Code'un proje ayarı. İlk oturumda Claude Code bunu `.claude/settings.json` olarak taşıyacak (Yol Haritası, Faz 0).
